# Experiment log

`results.csv` is the versionable aggregate experiment table. No row-level data or
predictions belong here. Use a new experiment ID for each changed configuration;
keep earlier results as reference points.

- **E01**: original Logistic Regression, single temporal holdout, public Kaggle
  AUC 0.88776 reported by the user. The original notebook and outputs are preserved.
- **E01-R**: the same Logistic Regression specification evaluated on all three
  rolling folds in notebook 02; this is a validation reference, not a new submission.
- **E02 / E03**: LightGBM without / with `time_step`.
- **E04 / E05**: XGBoost without / with `time_step`.

`local_auc` means the latest temporal fold (31–35). `fold_1_auc` through
`fold_3_auc` describe the fixed rolling protocol below. Mean is the unweighted
arithmetic mean; `std_auc` is population standard deviation (`ddof=0`). Leave
unmeasured folds and unsubmitted Kaggle scores blank, never zero. A rolling mean
must not be compared with a single-window score as if they used the same validation.

| Fold | Fit time steps | Validation time steps |
| --- | --- | --- |
| 1 | 1–20 | 21–25 |
| 2 | 1–25 | 26–30 |
| 3 | 1–30 | 31–35 |

The notebook refreshes only its own E01-R/E02–E05 rows, preserves unrelated
experiments and manually entered Kaggle scores, and checks configuration IDs before
reusing rows. Change the experiment ID when changing the model settings. E01 is
seeded once and never regenerated by notebook 02.

The JSON configuration and fold CSVs in this directory provide the settings,
split counts, and full-precision aggregate scores needed to interpret the table.
Generated run metadata and submissions remain in ignored `outputs/`.
