# BT4012 Fraud Analytics - E0906431

- **[e0906431.ipynb](e0906431.ipynb):** all preprocessing, model definitions, validation, training and submission generation in one notebook.
- **[requirements.txt](requirements.txt):** Python package dependencies.

The model combines tree ensembles, a tabular neural network and graph neural networks, then refines predictions using learned agreement between connected transactions. It trains on known labels and includes a chronological validation step.

## Run

1. Use Python 3.12 and install packages with `pip install -r requirements.txt`.
2. Place the competition-provided `train.csv`, `test.csv`, `txs_edgelist.csv` and `sample_submission.csv` in `data/raw/`.
3. Open the notebook and select **Restart Kernel and Run All**.

The submission is saved to `outputs/final_model/submission.csv`. No additional code files, external data or pretrained models are required. An empty output directory triggers full training; later runs may reuse checkpoints generated by the notebook.
