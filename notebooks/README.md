# Notebooks

`01_baseline.ipynb` is the executable first baseline. Restart the Python kernel
and run all cells to reproduce the temporal validation metrics and regenerate
`outputs/submission_baseline.csv`. Its committed output contains aggregate results
only; raw records and prediction files stay out of Git.

The full initial audit remains available in `scripts/audit_data.py`. See the root
README for environment setup and command-line execution instructions.
